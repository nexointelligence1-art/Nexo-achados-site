# Nexo Achados

Site de descoberta de produtos com curadoria, busca, categorias, ordenação por preço/avaliação e lista de favoritos salva no navegador.

## Rodar localmente

```sh
npm install
npm run dev
```

Para gerar uma build de produção:

```sh
npm run build
npm run preview
```

Os produtos de demonstração ficam no início de `src/App.tsx`. Atualize os dados e links de busca para incluir ofertas reais. Os links de compra nesta versão direcionam a uma busca pela loja indicada; imagens e fontes carregam de serviços externos.
